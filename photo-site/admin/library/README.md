# library/ — 정리할 사진 원본을 넣는 곳

구글 드라이브(또는 어디든)에서 **맥으로 내려받은 사진**을 이 폴더에 넣으세요.
그런 다음:

```bash
npm run organize        # http://localhost:4323
```

브라우저에서 미분류 사진을 **다중선택·드래그**로 컬렉션(카테고리)에 분류하고,
[게시]를 누르면 웹용으로 변환돼 사이트에 반영됩니다.

- 이 폴더의 사진들은 **git에 커밋되지 않습니다**(원본 보관용, 용량 큼).
- 게시하면 웹용(긴 변 2000px)으로 줄인 사본만 `public/photos/`에 들어가 커밋됩니다.
- 작업 상태는 `admin/organize-state.json`에 저장돼 중간에 꺼도 이어집니다.
